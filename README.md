## How it works

`main.ts` (Node 22, stdlib only, deterministic, no network) writes one satirical sentence — at most 320 characters — to `entry.txt` in the output directory (default `/output`, or `$MAKEFUN_OUTPUT_DIR` when set).

```sh
node main.ts
```
